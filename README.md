## Install or update

**InfinitumMassTexting-macOS.zip** is the only required download. It works on Apple silicon and Intel Macs with macOS 14 or later.

## Install or update — step by step

1. If a campaign is running, let it finish, or click Pause and wait until it says Paused.
2. Quit Infinitum using Infinitum → Quit in the top menu bar.
3. Download **InfinitumMassTexting-macOS.zip** under Assets below.
4. Open your Downloads folder and double-click that ZIP. An app named **InfinitumMassTexting.app** appears.
5. Drag that app into your **Applications** folder. If your Mac asks, choose **Replace**.
6. Open **Applications**, then double-click **InfinitumMassTexting**.
7. Existing contacts, logs and campaign progress stay on your Mac. A saved unfinished campaign stays paused. In Progress, choose **Check Connection**, then **Resume Campaign** when you are ready. Do not Archive & Reset if you want to continue the existing campaign.

For a new campaign, **Dry Run ON sends nothing**. Turn Dry Run OFF, review the complete messages and recipients, then explicitly confirm live sending. Allow control of Messages if macOS asks.
