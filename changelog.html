Changelog

1.0.3 · Build 1

Fixes the readiness-check confirmation loop. Saves approval, shows pause reasons, adds a no-send connection check and resumes unchanged campaigns directly. Adds preflight reports, suspicious-number review, permanent suppression, local history and audit exports, test variations, optional cooldowns, staged launch, business hours and consent records. Incoming opt-out replies are recorded manually.

1.0.2 · Build 1

Optional searchable contact library with editing, removal, first/last names, email, TikTok, Instagram and notes. Only phone is required. Paste CSV or text directly for one-time campaigns without saving library contacts. Includes import previews, duplicate protection and a downloadable CSV template.

1.0.1 · Build 1

Clear Dry Run versus Live guidance, local preparation countdown, polished mode banners and progress cards, sender identity setup, Apple activation-request guidance, version/build/commit display, and a fixed 60-second pause for new drafts. Existing campaign timing is preserved.

1.0.0 · Initial release

Native Mac campaign preparation, large contact imports, manual entry, personalized variations, dry runs, reviews, deterministic batches, pause and recovery, local CSV/debug logs, onboarding, native Settings, menu-bar controls, local opt-outs, update checks and data controls.

Apple Messages permission and a configured account are required for live sending. No delivery or spam-filter outcome is guaranteed.
